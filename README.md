# مدیریت مالی شخصی

یک وب‌اپ ساده و متن‌باز برای مدیریت مالی شخصی، ساخته‌شده برای آیفون (PWA). فارسی، راست‌به‌چپ، با تقویم شمسی و ارقام فارسی. تمام داده‌ها فقط روی دستگاه کاربر (localStorage) ذخیره می‌شود؛ بدون سرور، بدون ثبت‌نام و بدون ردیابی.

## امکانات

- ثبت، ویرایش و حذف تراکنش (درآمد/هزینه) با دسته، یادداشت و تاریخ شمسی
- صفحه‌ی اصلی با تراز ماه، جمع درآمد و هزینه، جابه‌جایی بین ماه‌ها
- جستجو و فیلتر (متن، نوع، دسته، همه‌ی ماه‌ها)
- دسته‌بندی قابل ویرایش و بودجه‌ی ماهانه‌ی اختیاری برای هر دسته
- تراکنش‌های تکراری ماهانه
- حساب‌های بانکی: هر کارت یک حساب جدا با موجودی خودش، انتخاب اختیاری حساب هنگام ثبت تراکنش و پنجره‌ی تراکنش‌های هر حساب
- طلب و بدهی (با پرسش حساب هنگام تسویه)
- قسط و وام با یادآوری سررسید، مرتب‌شده بر اساس نزدیک‌ترین سررسید (با پرسش حساب هنگام پرداخت)
- هدف‌های پس‌انداز
- هر بخش تعهدات دو قسمت «جاری» و «انجام‌شده» دارد
- نمودار سهم دسته‌ها و مقایسه‌ی درآمد و هزینه‌ی ۳ ماه اخیر
- ریال (پیش‌فرض) یا تومان
- حالت روشن/تاریک خودکار بر اساس تنظیم سیستم
- پشتیبان‌گیری و بازگردانی (JSON) و خروجی CSV برای اکسل
- کار آفلاین

## اجرا و انتشار

برنامه فقط HTML/CSS/JS ساده است و نیازی به build ندارد.

اجرای محلی:

```bash
python3 -m http.server 8000
# سپس http://localhost:8000
```

انتشار روی GitHub Pages:

1. کد را در یک مخزن GitHub قرار دهید.
2. به **Settings → Pages** مراجعه کنید.
3. در **Build and deployment** گزینه‌ی **Deploy from a branch** را انتخاب کنید، سپس شاخه‌ی `main` و پوشه‌ی `/ (root)` را برگزینید.
4. پس از یکی دو دقیقه، نشانی `https://<username>.github.io/<repo>/` فعال می‌شود.

## نصب روی آیفون

۱. نشانی را در **Safari** باز کنید.
۲. دکمه‌ی اشتراک‌گذاری را لمس کنید.
۳. **Add to Home Screen** و سپس **Add** را انتخاب کنید.

در Safari آیفون، تا زمانی که برنامه به صفحه‌ی اصلی اضافه نشده باشد، فقط راهنمای نصب نمایش داده می‌شود. دلیل آن این است که Safari و برنامه‌ی نصب‌شده حافظه‌ی جداگانه دارند و iOS ممکن است داده‌ی سایت را پس از مدتی عدم استفاده پاک کند.

## نکته‌ها

- یادآوری سررسید قسط‌ها داخل خود برنامه (صفحه‌ی خانه و نشان روی تب «تعهدات») نمایش داده می‌شود. اعلان پس‌زمینه ندارد، چون برای آن سرور لازم است.
- تراکنش‌های تکراری هنگام باز شدن برنامه ثبت می‌شوند.
- مبلغ‌ها به ریال ذخیره می‌شوند و با تغییر واحد، فقط نمایش عوض می‌شود. با این روش حتی مبلغ‌های غیرمضرب بر ۱۰ (مثل ۱۰۰۱ ریال) بدون اعشار و بدون گم‌شدن ذخیره می‌شوند.
- موجودی هر حساب از «موجودی اولیه + تراکنش‌های متصل به آن» محاسبه می‌شود. با حذف حساب، تراکنش‌های آن حذف نمی‌شوند و فقط از حساب جدا می‌شوند.
- هنگام ثبت طلب یا بدهی‌ی جدید، به‌طور پیش‌فرض یک تراکنش هم ثبت می‌شود (بدهی با دسته‌ی «قرض» به‌عنوان درآمد و طلب با دسته‌ی «قرض» به‌عنوان هزینه) تا موجودی حساب‌ها درست بماند. این گزینه قابل خاموش‌کردن است.
- تسویه‌ی بدهی یا طلب یک تراکنش می‌سازد (بازپرداخت بدهی هزینه و دریافت طلب درآمد است) و در تراز ماه حساب می‌شود، اما در نمودار سهم دسته‌ها نمی‌آید و در کارت «تسویه‌ی بدهی و طلب» گزارش‌ها جدا نمایش داده می‌شود.
- بعد از انتشار نسخه‌ی جدید، به کاربر پیام «نسخه‌ی جدید» نمایش داده می‌شود و با انتخاب «به‌روزرسانی»، برنامه از صفحه‌ی خانه دوباره بارگذاری می‌شود و داده‌ها حفظ می‌شوند. برای اطمینان از تازه‌شدن کش، مقدار `VERSION` را در `sw.js` افزایش دهید.

## ساختار

```
index.html
css/style.css
js/jalali.js     تبدیل تاریخ شمسی/میلادی
js/store.js      داده، ذخیره‌سازی و منطق برنامه
js/app.js        رابط کاربری
sw.js            کش آفلاین
manifest.webmanifest
icons/
fonts/           فونت وزیرمتن و مجوز آن
```
